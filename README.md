# Aceros ISR

<img src="https://github.com/user-attachments/assets/e94dfa5e-6a5d-433f-9879-b4d739e72b2c" alt="Aceros ISR - IMG" width="300px">

Aceros ISR es una aplicación móvil habilitada para Android y próximamente para IOS en el que se busca automatizar y gestionar procesos internos dentro de un taller de herrería mejorando la calidad y eficiencia operativa, tener un control del stock para cada uno de los materiales y una mejor comunicación interna dentro del taller.     


## Documentación 🚀

_Para el sistema se diseñó un manual para la instalación y comprensión del sistema._

* [Manual de usuario](https://drive.google.com/file/d/19da2qGXWcMOycp_pj6NINk0KYQeZig-2/view?usp=sharing) - Manual para la instalación y uso.

### Pre-requisitos 📋

_Para ejecutar el sistema en su versión mas actual se necesitan las siguientes condiciones:_

- Tener un dispositivo móvil con sistema operativo Android. 
- Contar con acceso a internet para descargar la app y sincronizar datos. 
- Crear una cuenta o ser registrado previamente por el supervisor. 
- Acceso al correo electrónico para recuperación de credenciales en caso de olvido.

### Apk 🔧

_Para poder usar la aplicación puedes descargar un fichero ejecutable [APK](apk) (Aceros ISR.apk)  para instalar directamente en tu dispositivo Android. Deberás permitir la instalación de aplicaciones fuera de la tienda._
